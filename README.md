- **UI 基线**：以 `docs/UI-INTERFACE.md` 为准

## 核心功能界面

### 衣橱

当前“衣橱”页面包含：

- 搜索：支持按名称 / 品牌 / 备注搜索；
- 成员筛选：按家庭成员筛选衣物；
- 种类筛选：上衣、下装、连衣裙、外套、内衣、袜子等；
- 颜色筛选：红色、橙色、黄色、绿色、蓝色、紫色、黑色等；
- 季节筛选：春、夏、秋、冬、四季通用；
- 状态筛选：在库、借出、已处理；
- 衣物卡片：照片、名称、分类、颜色、数量；
- 新增：右下角 `+` 快速新增衣物；
- 底部导航：看板 / 衣橱 / 我的。

## 项目结构

- `miniprogram/`：微信小程序前端源码
- `docs/`：开发检查记录和界面说明

## V1.0 开发原则

后续代码修改优先保证现有核心功能稳定，再逐步进行 UI、交互和业务能力优化。Codex 继续开发前，应先阅读 `docs/UI-INTERFACE.md` 和相关页面源码。
