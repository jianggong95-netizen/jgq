# 优家库 V1.0 软件界面说明

本说明根据当前优家库微信小程序的实际界面截图整理，用于后续 UI 优化、功能开发和 Codex 继续开发时作为界面基线。

## 1. 页面定位

当前截图对应 **“衣橱”** 页面，是优家库的核心衣物管理页面。

页面主要目标：

- 快速搜索衣物；
- 按家庭成员、衣物种类、颜色、季节、状态筛选；
- 以卡片方式查看衣物照片、名称、分类和数量；
- 通过右下角“+”快速新增衣物；
- 通过底部导航切换“看板 / 衣橱 / 我的”。

## 2. 页面布局

### 2.1 顶部导航栏

- 页面标题：**衣橱**；
- 右侧保留微信小程序标准菜单区域；
- 顶部采用绿色作为主品牌色。

### 2.2 搜索区域

顶部导航栏下方为搜索区域：

- 搜索输入框提示：`搜索名称 / 品牌 / 备注`；
- 右侧提供绿色“搜索”按钮；
- 支持按衣物名称、品牌、备注进行查询。

### 2.3 筛选区域

搜索区域下方提供多组筛选条件：

| 筛选项 | 当前示例 |
|---|---|
| 成员 | 管理员、慧慧 |
| 种类 | 上衣、下装、连衣裙、外套、内衣、袜子等 |
| 颜色 | 红色、橙色、黄色、绿色、蓝色、紫色、黑色等 |
| 季节 | 春、夏、秋、冬、四季通用 |
| 状态 | 在库、借出、已处理 |

筛选项采用横向排列的圆角标签样式，内容较多时允许横向滚动。

### 2.4 衣物卡片列表

主体区域使用双列卡片布局展示衣物：

- 每张卡片顶部显示衣物照片；
- 中部显示衣物名称，例如“花裙子”“碎花裙”；
- 下一行显示分类和颜色，例如“连衣裙 · 红色”“连衣裙 · 多色”；
- 底部显示数量，例如 `x1`；
- 卡片采用圆角、浅色背景和图片优先的视觉形式。

当前截图中的示例数据：

1. 花裙子：连衣裙、红色、数量 x1；
2. 碎花裙：连衣裙、多色、数量 x1。

### 2.5 新增按钮

页面右下角提供悬浮圆形 `+` 按钮：

- 用于快速新增衣物；
- 保持明显的品牌绿色；
- 位于内容区右下方，避免遮挡底部导航。

### 2.6 底部导航

底部固定导航包含三个入口：

- **看板**：查看家庭衣物数据概览；
- **衣橱**：当前衣物管理页面，选中状态使用绿色突出显示；
- **我的**：个人及系统相关功能。

## 3. 当前 UI 风格基线

- 主色：绿色系；
- 页面背景：白色/浅灰色；
- 搜索框和筛选标签：浅灰色圆角；
- 操作按钮：绿色圆角；
- 衣物展示：大图 + 信息卡片；
- 页面整体偏简洁、家庭生活类工具风格。

## 4. V1.0 后续 UI 优化重点

后续修改代码时，原则上不要破坏现有核心布局。优先关注：

1. 小屏设备上的筛选项横向滚动体验；
2. 长名称、长品牌名称的文字截断和换行；
3. 图片加载失败时的占位图；
4. 网络较慢时的加载状态；
5. 空衣橱时的空状态提示和新增引导；
6. 搜索、筛选条件变化后的加载反馈；
7. 卡片点击区域和新增按钮的可操作性；
8. 不同屏幕尺寸下双列卡片的自适应效果。

## 5. 给 Codex 的开发约束

后续 Codex 修改衣橱页面时，应先阅读本文件和 `miniprogram/pages/closet/` 目录，再进行代码修改。

UI 改动应遵循：

- 保持“衣橱”页面核心信息结构不变；
- 优先修复实际 Bug，再进行视觉优化；
- 不随意删除已有筛选条件；
- 不改变后端接口字段，除非同时确认后端契约；
- 每次修改后进行 JavaScript/JSON 静态检查；
- 重要 UI 改动应在微信开发者工具和真机上验证。
